# Bloom Rescue — Smart Hints v0.4

Mobile-first water-pipe rescue puzzle playable in a web browser.

## Play

GitHub Pages: https://impulse456-byte.github.io/bloom-rescue/ (after Pages is enabled from `main` / `(root)`).

## Features

- Fixed, nonrotatable START and FINISH endpoints.
- Two free smart hints per puzzle, then 25 coins for more.
- Level 1 tutorial and procedural puzzles.
- Daily seeded challenge, coins, and progress stored locally.

## Status

Prototype only. No advertising, in-app purchases, cloud saves, or live leaderboard is implemented yet.

## Pages setup

Repository Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
